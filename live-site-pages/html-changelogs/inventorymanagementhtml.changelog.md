## [v01.61w] — 2026-05-04 10:32:56 AM EST — v12.48r

### Fixed
- After scanning a barcode for an item that already exists, the Update button is now visible right away — no need to nudge the quantity to make it appear. One-click confirmation matches the obvious intent.
- The +/- buttons now skip past 0 when adjusting an existing item's quantity. Stepping down from +1 goes directly to -1 (and back up the same way), since 0 has no effect.
